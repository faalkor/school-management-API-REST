# School Management API REST 🚀

API REST para gerenciar estudantes, suas fotos e informações, desenvolvida em **Node.js/JavaScript**.  
Este backend permite criar, listar, atualizar e remover registros de alunos, além de outros recursos relacionados à gestão escolar.

---

## 🧪 Tecnologias

Este projeto foi construído com:

- **Node.js**
- **Express**
- **JavaScript**
- **npm**
- Variáveis de ambiente com `.env`  

---

## 📦 Pré-requisitos

Antes de rodar o projeto, instale:

✔ **Node.js** (versão 14 ou superior)  
✔ **npm**

---

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/faalkor/school-management-API-REST.git
cd school-management-API-REST
```

2. Instalar Dependências:

```bash
npm install
```

3. Preencher variáveis de ambiente:

```bash
cp .env.example .env
```

4. Iniciar o servidor:

```bash
npm start
```

5. Acesse o projeto pelo navegador:

```bash
ex: http://localhost:3000
```
